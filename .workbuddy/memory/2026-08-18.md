## 接入 jsDelivr CDN 输出可播放版本（同日）

### 调研结论
- git 做 CDN：jsDelivr 服务 GitHub 分支，URL `https://cdn.jsdelivr.net/gh/USER/REPO@BRANCH/path`；单文件 ≤20MB；分支缓存 12h
- sound-assets 盘点：GitHub SirusChen/git-database@sound-assets 共 50 个 mp3（animals9/funny12/game5/happy7/instruments5/nature5/weird7），全部被 jsDelivr 索引，实际 URL 返回有效 MP3
- 有趣音源：SoundDino 免费免版税（相机快门/键盘）；爱给网/站长素材有剃须刀（需确认授权）。sound-assets 缺「电子产品日常」类

### 落地
- `config/cdn.js`：CDN_BASE 切到 jsDelivr sound-assets，IS_DEV=false，新增 REMOTE_SOUNDS_ENABLED=false（远程尚无 sounds.json）
- `scripts/gen_sounds_config.py`：整理 50 音源 → sounds.json（emoji+中文标签+7色循环）
- `config/sounds.json`：50 个声音，url 相对路径 `animals/cat-meow.mp3`
- `pages/index/index.js`：_fetchRemoteSounds 跳过条件加 !REMOTE_SOUNDS_ENABLED
- 删除 Day1 本地 `/audio/*.wav` 与 generate_sounds.py 占位

### 关键指标
- 主包 41KB（音频全走 CDN）
- 50 个真实音效，url 零格式错误
- 微信要求 downloadFile 白名单加 cdn.jsdelivr.net；国内不稳可用 fastly/gcore/testingcf.jsdelivr.net 镜像
