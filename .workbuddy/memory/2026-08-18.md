## 接入 jsDelivr CDN 输出可播放版本（同日）

### 调研结论
- git 做 CDN：jsDelivr 服务 GitHub 分支，URL `https://cdn.jsdelivr.net/gh/USER/REPO@BRANCH/path`；单文件 ≤20MB；分支缓存 12h

## 提审方案价格 + 备案域名调研（2026-08-18 晚）

### 背景
资源实测 50 个 mp3 共 **4.85MB**，体量极小 → 所有云方案免费额度内月成本均为 ¥0。方案选择关键不在价格，而在「备案摩擦」与「热更新能力」。

### 价格对比（2026-08 实测）
| 方案 | 备案要求 | 免费额度 | 超出费用 | 4.85MB月成本 | 热更新 |
|---|---|---|---|---|---|
| 本地分包 | 无(无域名) | 永久¥0 | — | ¥0 | ❌重发版 |
| CloudBase cloud:// | **免白名单** | 6月免费体验 | 个人版¥19.9/月 | ¥0→¥19.9 | ✅ |
| 腾讯 COS | 默认域名已备案+加白名单 | 50GB×6月 | 0.099元/GB/月+流出0.5元/GB | ¥0(6月内) | ✅ |
| 阿里云 OSS | 默认域名已备案+加白名单 | 40GB×6月 | 0.12元/GB/月+流出0.5元/GB | ¥0(6月内) | ✅ |
| 七牛 Kodo | 需自备已备案域名 | 10GB/月 | 0.099元/GB/月+流出0.29元/GB | ¥0 | ✅(但默认30天临时域名) |

### 关键澄清：两个备案不是一回事
1. **小程序备案（应用备案）**：任何方案都躲不掉，mp.weixin.qq.com 提交，免费约1-2周，不需要自己的服务器。
2. **服务器域名 ICP 备案**：仅当白名单加「自有/非厂商已备案」域名（Qiniu自定义域名/自建后端）时才需要；需域名实名+国内服务器+材料，管局1-3周。

### 自有备案域名路线成本（仅 Qiniu/自建 才需要）
- 域名 .cn 首年¥26-38(续费¥42) / .com 首年¥52-85(续费¥78-95)
- 国内轻量服务器 2核2G 首年¥38-68（续费刺客；阿里云ECS经济型¥99/年续费同价更稳）
- SSL 免费DV ¥0；首年≈¥70-110，次年≈¥140-540；备案后服务器须持续有效
- **结论**：对 4.85MB，这是最贵最慢且最不需要的路，不建议。COS/OSS 默认域名已备案直接加白名单即可，或 CloudBase 免白名单，或本地分包零配置。

### 决策建议
保留热更新+摩擦最小 → CloudBase(cloud://)；想当天过审 → 本地分包；有备案域名情结/传统CDN → COS/OSS。勿走 Qiniu 自有域名备案路线。

## 落地：本地分包方案（2026-08-18 晚）

### 决策
用户拍板「改成本地分包的方案」：音频本地打包，免 CDN/域名/备案，永久¥0。放弃 jsDelivr。

### 实现要点
- 50 个 mp3（4.85MB）从 jsDelivr 下载到本地，按体积均衡拆成 3 个分包（每包≤2MB）：
  - audio1: ocean+thunder (1845KB)
  - audio2: wind+rain+drum+drum-roll+evil-laugh+piano+air-horn (1848KB)
  - audio3: 其余 41 个 (1271KB)
- 每个分包含占位页 `pages/holder/holder.{js,json,wxml,wxss}`（保证分包合法性，跨开发者工具版本稳妥）。
- `app.json` 增加 subpackages（root: subpackages/audioN, name: audioN, pages: [pages/holder/holder]）。
- `config/sounds.js`：url 改为本地绝对路径 `/subpackages/<pkg>/<cat>/<file>.mp3`，新增 `pkg` 字段。
- `config/cdn.js`：切本地模式，resolveUrl 原样返回本地路径，resolveShareImg 返回空。
- `utils/audio.js`：play() 先 `wx.loadSubPackage` 按需加载所属分包，成功后再 set src 播放；用 `_loadedPkgs/_loadingPkgs` 防重复。
- `pages/index/index.js`：去掉远程 sounds.json 拉取，直接用本地打包配置。
- 新增 `scripts/download_audio.js`（下载）、`scripts/build_local_subpackages.js`（移动+生成占位页+改写 sounds.js）；`gen_sounds_config.py` 改为生成本地配置（PKG 映射与 node 脚本一致）。

### 关键约束（踩坑点）
- 单包/主包 ≤2MB，总包 ≤20MB → 4.85MB 必须拆 ≥3 包。
- preloadRule 聚合预下载限额 2MB（主包页预下载的分包总体积须≤2MB）→ 不能用 preloadRule 一次性预下载 4.85MB；改用按需 `wx.loadSubPackage` 绕开。
- 纯资源分包合法（pages 可空或用占位页）；为稳妥选占位页方案。

### 校验
- 7 个 JS 全部 node --check 通过；50 音频文件 0 缺失；3 占位页 0 缺失；3 包均 ≤2MB；app.json 合法；miniprogram 内无 jsdelivr 残留引用。
