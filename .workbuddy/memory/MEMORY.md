# sound-master 项目长期记忆

## 项目定位
声音按钮微信小程序：用户点击 emoji 按钮播放对应声音，音频走 CDN，主打快速上线 + 社交裂变获客。

## 技术栈
- 微信小程序原生开发（WXML/WXSS/JS）
- 微信云开发（云函数 + 数据库，二期启用）
- 本地分包托管音频（miniprogram/subpackages/audioN）；sounds.json / sounds.js 为本地清单

## 关键架构决策
- **音频引擎**：单例 `wx.createInnerAudioContext`，切换 src 自动 stop 前一个，避免 iOS 多音频叠加
- **配置清单**：本地兜底配置用 `config/sounds.js`（`module.exports`）——小程序 `require` **不支持直接 require `.json`**，否则报 `module 'config/xxx.json.js' is not defined`；`sounds.json` 仅作为 CDN 热更新清单（远程 wx.request 拉取）。`scripts/gen_sounds_config.py` 一次性生成这两个文件。
- **emoji 按钮**：字符直接渲染，0 字节图片，跨平台一致
- **分享获客**：每个声音独立分享卡片，落地带 soundId 自动播放
- **音频分包**：50 个 mp3（4.85MB）拆为 3 个本地分包 audio1~3（各≤2MB），主页点击时按需 `wx.loadSubPackage` 加载；主包仅代码

## 域名白名单 / CDN 备案硬约束（关键！）
- 微信**所有**服务器域名（request / downloadFile / uploadFile / socket）正式发布前**必须完成 ICP 备案**，否则无法加入白名单、提审/上线会卡住。
- 当前 `cdn.jsdelivr.net` 是**境外域名、无国内备案** → 只能用于「开发版/体验版 + 不校验合法域名」调试，**不能用于正式发布**。
- 推荐用于正式发布的免费 CDN（已备案或免备案）：
  1. **微信云开发静态托管 / 云存储**：首推。cloud:// 协议与微信同源，**真正免白名单配置**（无需 ICP 备案）；项目已 `wx.cloud.init` 且有 cloudfunctions/，改造成本最低。
     - 免费体验版：3,000 资源点/月，有效期 6 个月（活动至 2026-12-31，可 0 元续期）；**但小程序发布上线后免费环境第 15 天到期**，长期使用需转付费 → 个人版 ¥19.9/月（40,000 点、2GB 存储、5GB CDN 流量）；按量：CDN 流量 0.21 元/GB、存储 0.1 元/GB/日、CDN 回源 0.15 元/GB。
  2. **腾讯云 COS / 阿里云 OSS**：默认 `*.myqcloud.com` / `*.aliyuncs.com` 域名**已备案**，可直接加白名单。COS 新用户 50GB 标准存储×6 个月免费，之后 0.099 元/GB/月、公网流出 0.5 元/GB 起；OSS 新用户 40GB 标准存储×6 个月免费，之后 0.12 元/GB/月、公网流出 0.5 元/GB 起。仍须手动配 request/downloadFile 白名单。
  3. **七牛云 Kodo（注意坑）**：实名后每月免费 10GB 存储 + 10GB CDN 回源 + GET 100 万次；超出 标准存储 0.099 元/GB/月、外网流出 0.29/0.26 元/GB、CDN 回源 0.15 元/GB。**但七牛给的是 30 天临时测试域名，生产环境必须自备「已备案」域名绑定**——所以它并不能帮你绕开备案，只是免费存资源。除非你有已备案域名，否则不适合做正式发布。
- **真正「零备案」的只有两条路**：① 微信云开发 cloud://（免白名单）；② 本地分包（无域名）。其余云厂商只是「默认域名已备案、可加白名单」，仍需在微信后台配置白名单。
- 仅适合开发/体验版（境外无备案）：jsDelivr(含 fastly/gcore/testingcf 镜像)、Cloudflare Pages/R2、Vercel、Netlify、GitHub Pages。
- **提审零备案捷径（备选）**：50 个 mp3 实测约 **4.85 MB**（< 20MB 分包上限），可直接打进**分包**本地播放，免域名、免备案、免白名单、永久 ¥0；缺点：更新声音需重新发版。主包仍需 < 2MB，音频放分包。

**已确定方案：本地分包**（2026-08-18 落地）。音频打包进 `miniprogram/subpackages/audio1~3`，主页点击时按需 `wx.loadSubPackage` 加载对应分包；每个分包含占位页 `pages/holder/holder` 保证合法性；免域名/免备案/免白名单，永久 ¥0，无热更新（改声音需重发版）。CDN(jsDelivr) 已弃用。

## 备案认知纠偏（2026-08 调研，关键！）
- **两个"备案"不是一回事**：
  1. **小程序备案（应用备案）**：2023-09 起所有微信小程序强制，在 mp.weixin.qq.com 提交，主体=小程序运营者，腾讯初审→管局，免费约 1-2 周，**任何方案都躲不掉**，且不需要你自己的服务器。
  2. **服务器域名 ICP 备案**：仅当你在「服务器域名白名单」里加入**自己控制的、非厂商已备案**域名（如 Qiniu 自定义域名、自建后端）时才需要；需「已实名域名 + 国内服务器(接入商) + 材料」，管局审核 1-3 周，免费但耗时。
- **本项目结论**：sound-master 走 本地分包 / CloudBase(cloud://免白名单) / COS / OSS(默认域名已备案) 都**不需要你做域名 ICP 备案**，只需配置白名单或什么都不用配。只有坚持用 Qiniu/自建时，才需要自费备案。
- **自有备案域名路线成本（2026）**：域名 .cn 首年 ¥26-38(续费¥42)、.com 首年¥52-85(续费¥78-95)；国内轻量服务器 2核2G 首年 ¥38-68（续费刺客，选阿里云ECS经济型¥99/年续费同价更稳）；SSL 免费DV ¥0。首年≈¥70-110，次年≈¥140-540。且备案后服务器须持续有效（空壳备案会被注销）。对 4.85MB 资源，**这是最贵最慢且最不需要的路**，不建议。
